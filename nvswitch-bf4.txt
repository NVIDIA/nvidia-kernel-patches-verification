# support. Earlier v6.18.y kernels may need further fixes that are

# in upstream order, so each group can be cherry-picked as listed. On a
# v6.19 base the v6.19 group is already present.
#
# The 19 non-upstream BlueField-4 patches from the same list are in
# nvswitch-bf4-addendum.txt.
